# 세모 게임실

4학년 학생들이 종이에 그린 게임 기획서(수학 「삼각형」 + 「평면도형의 이동」)를
**기획서의 규칙과 숫자 그대로** 플레이할 수 있게 옮긴 STEAM 수업용 웹앱.
학생은 게임을 해 보고 AI 한줄평·기획 평가서를 읽은 뒤, 디버깅 활동지에 "숫자를 얼마로 정할지" 직접 적는다.

5모둠 중 2모둠이 제출(2026-09-30 스캔). 나머지 3모둠은 홈 아래쪽에 빈 자리로 표시된다.

## 게임 3종

| # | 게임 | 기획 (모둠) | 삼각형 개념 |
| --- | --- | --- | --- |
| 1 | 미션 삼각형 돌리기 | 아야어여우유어이 (A) | 예각·직각·둔각 구별 + 90° 돌리기. 쉬움 6개 → 보통 30개, 종류별 번호 |
| 2 | 피자 자르기 | 키위 맛 우유 (B) | 꼭짓점 세 곳을 찍어 예각·둔각 조각 만들기. 세 각이 화면에 나온다 |
| 3 | 물고기 잡기! | 잼민이 아닌데요? (B) | 빛나는 지느러미 삼각형 구별. 바다·심해 속·강, 한 번 틀리면 실패 |

## 평가서 판정 집계 (1차)

| 게임 | ○ | △ | ✕ | 1순위 문제 |
| --- | --- | --- | --- | --- |
| 미션 삼각형 돌리기 | 2 | 3 | 1 | 틀려도 잃는 것이 없음. 번호만 보고 찍어도 목표 하나에 평균 1번 틀리면 찾음 |
| 피자 자르기 | 3 | 2 | 1 | 아무렇게나 세 점 찍어도 69~70%가 둔각 → 둔각 손님이 너무 쉬움 |
| 물고기 잡기! | 3 | 2 | 0 | 심해 지느러미는 직각과 6° 차이인데 목숨이 1개 |

판정 근거 수치는 `scripts/smoke_test.js` 자동 플레이에서 나온 값(`scripts/measure.json`).

## 구조

```
index.html        홈(게임 포스터 3장 + 모둠 제출 현황) + 게임 화면 + 모달(기획안·AI 평가·편지)
review.html       AI 기획 평가서 인쇄본 (A4, 게임별 2쪽)
worksheet.html    디버깅 활동지 인쇄본 (A4, 안내 1 + 게임 3)
css/app.css       공통 화면 · 평가서 모달
css/games.css     게임별 무대
js/core.js        효과음 · 삼각형 기하(각으로 삼각형 만들기, 각 재기, 판정) · GameBase · 화면 전환
js/data.js        게임 정보 · AI 한줄평 · 홈 포스터 SVG · 모둠 · 편지(LETTERS)
js/review.js      평가 6항목 · 게임별 평가 데이터 (모달·인쇄 공용)
js/games/*.js     게임 하나당 한 파일. 값은 맨 위 paramSpec 한 곳에만
data/             원본 스캔 PDF (gitignore — 지운 이름 흔적이 있어 공개하지 않음)
source_images/    게임별 기획서 쪽 (90° 회전 보정, g1 1쪽 지운 닉네임 흔적 가림)
extracted_games.md 기획서 분석서
scripts/          smoke_test.js (jsdom 자동 플레이) · browser_check.js (Chrome 헤드리스 점검)
```

바닐라 HTML/CSS/JS. `python -m http.server` 로 열면 된다. 글꼴(Pretendard·JetBrains Mono)만 CDN이고 없어도 시스템 글꼴로 뜬다.

## 원칙

- 기획서 수치는 고치지 않는다. 기획서에 없는 값만 채우고 평가서 "AI가 정한 값" 표와 편지에 모두 적었다.
- 게임 안에 밸런스 조절 UI는 없다. 값은 기획 학생이 활동지 ③에 적는다.
- 2차 사이클: 활동지 스캔 → `paramSpec.orig` 수정 → 평가서·한줄평·활동지 "지금 값" 갱신 → 재배포 → `LETTERS[n]`에 2차 편지 추가.

## 검증

```
python -m http.server 8765
NODE_PATH=<jsdom·puppeteer-core 설치 폴더>/node_modules node scripts/smoke_test.js
NODE_PATH=<...>/node_modules node scripts/browser_check.js <스크린샷 폴더>
```

- jsdom: 세 게임 클리어·실패 경로, 쉬움→보통 전환, 점수 규칙, 맵 3개, 게임 나가면 타이머 정리.
- Chrome(1366×657 크롬북, 1920×1080 전자칠판): 세로 스크롤 0, 실제 마우스 클릭(삼각형 선택·버튼·가위질·낚시), 모달, Esc 동작, 콘솔 오류 0, 인쇄 쪽수(활동지 4쪽, 평가서 6쪽).
